# Симуляция вождения — Автошкола

Браузерная симуляция вождения от первого лица на Babylon.js. Игрок управляет автомобилем по городу из перспективы водителя, сталкиваясь с дорожными ситуациями, которые оцениваются через Deepseek API.

## Требования

- Python 3.x (для локального HTTP-сервера) или любой статический HTTP-сервер
- Node.js 18+ (для прокси-сервера)
- API-ключ Deepseek

## Запуск

### 1. Установка зависимостей прокси-сервера

```bash
cd server
npm install
```

### 2. Настройка переменной окружения

Прокси-сервер требует переменную окружения `DEEPSEEK_API_KEY` с вашим API-ключом Deepseek.

**Windows (CMD):**
```cmd
set DEEPSEEK_API_KEY=ваш_ключ_здесь
```

**Windows (PowerShell):**
```powershell
$env:DEEPSEEK_API_KEY = "ваш_ключ_здесь"
```

**Linux / macOS:**
```bash
export DEEPSEEK_API_KEY=ваш_ключ_здесь
```

> Если переменная не задана, прокси-сервер выведет ошибку и завершится.

### 3. Запуск прокси-сервера

```bash
cd server
node index.js
```

Сервер запустится на порту `3001` (или на порту из переменной `PORT`).

### 4. Запуск фронтенда

Откройте новый терминал в корневой директории проекта и запустите локальный HTTP-сервер:

**Python:**
```bash
python -m http.server 8000
```

**Node.js (npx):**
```bash
npx serve .
```

Затем откройте в браузере: [http://localhost:8000](http://localhost:8000)

## Управление

| Клавиша | Действие |
|---------|----------|
| `W` / `↑` | Ускорение |
| `S` / `↓` | Торможение |
| `A` / `←` | Поворот влево |
| `D` / `→` | Поворот вправо |

> Управление блокируется во время активного сценария (когда отображается UI-оверлей с выбором действий).

## Переменные окружения

| Переменная | Обязательная | Описание |
|------------|:------------:|----------|
| `DEEPSEEK_API_KEY` | ✓ | API-ключ для доступа к Deepseek API. Используется прокси-сервером для авторизации запросов. |
| `PORT` | — | Порт прокси-сервера (по умолчанию: `3001`) |

## Деплой на Render

Проект настроен для деплоя на [Render](https://render.com) как **Web Service**. Сервер одновременно раздаёт статику (фронтенд) и проксирует API-запросы.

### Настройка на Render

1. Создайте **Web Service** и подключите репозиторий
2. Настройки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** `Node`
   - **Node Version:** `18` или выше
3. Добавьте переменную окружения:
   - `DEEPSEEK_API_KEY` = ваш API-ключ Deepseek

Render автоматически задаёт переменную `PORT`, сервер её использует.

### Как это работает

- `server/index.js` раздаёт все статические файлы (index.html, js/, assets/) из корня проекта
- API-запросы на `/api/evaluate` проксируются к Deepseek API
- Один процесс, один порт — всё что нужно для Render
